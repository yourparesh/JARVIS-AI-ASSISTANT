# 🤖 JARVIS AI Assistant

A Python-based AI Voice Assistant inspired by JARVIS.  
This project is designed to understand voice commands and perform different tasks using Python and AI technologies.

## ✨ Features

- 🎙️ Voice-based interaction
- 🗣️ Speech recognition
- 🔊 Text-to-speech response
- 🤖 AI-powered responses
- 🌐 Perform web-based tasks
- 💻 Execute useful computer tasks
- 🔐 API key based AI integration

## 🛠️ Technologies Used

- Python
- Google Gemini API
- Speech Recognition
- Text-to-Speech
- APIs
- Git & GitHub
